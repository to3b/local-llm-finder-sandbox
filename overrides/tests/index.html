Want a repeatable benchmark for your own baseline? If you already use Ollama and Python 3, the optional helper runs five short tests and saves a file you can import above. It only contacts Ollama on your computer and never submits automatically.

Download Ollama test helper
python llf-test.py

On Windows you may need py llf-test.py; on macOS/Linux, python3 llf-test.py. The helper lists your installed models and asks you to pick one.

Generation speed is measured separately from prompt processing. Reported loaded GPU memory is not a peak-memory measurement. Benchmarks don’t measure answer quality.
