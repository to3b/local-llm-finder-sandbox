Example prompts for a consistent baseline

Use a model already installed in your usual app. Choose one prompt below, or share what you tried yourself. You never need to send the model’s response.

  1. Start a fresh chat. Keep the model, quantization and GPU/CPU settings the same.
  2. If your app exposes these settings, use a 4096-token context, 128-token reply limit and temperature 0. Keep thinking mode consistent. If a setting is unavailable, leave its form field blank.
  3. Run the chosen prompt once to warm up, then run it three more times in fresh chats. Use the same prompt and settings each time.
  4. If your app shows generation speed, report the middle of those three speeds. Leave speed blank if it does not. Prompt-processing speed is a different measurement.

Using your own test? Choose “My own test” under optional settings and briefly describe the task if useful. A quick observation is welcome even without repeated runs.

Prefer an automatic baseline? The optional Ollama/Python helper warms up, runs five tests, and saves statistics only. It defaults to the writing prompt above, uses seed 42, and never uploads prompts or responses.

Download Ollama test helper
python llf-test.py

Windows: py llf-test.py. macOS/Linux: python3 llf-test.py. Choose an installed model when asked. For the coding baseline, add --prompt code. Import the saved JSON file above when ready.

Compare matching prompts and settings. Manual reports remain observations; reviewed repeated measurements can inform future speed calibration. Loaded GPU memory is not peak memory, and speed does not measure answer quality.
